# Kalimantan Hotspot Forecasting

An MLOps project for forecasting daily hotspot activity across regencies and cities in Indonesian Kalimantan using NASA FIRMS data.

## Project Overview

This project aims to build a reproducible machine learning workflow for forecasting daily hotspot activity in Indonesian Kalimantan.

The project uses NASA FIRMS active fire data as the primary data source and is designed to support future stages such as data ingestion, preprocessing, feature engineering, model training, evaluation, monitoring, and retraining.

## Project Objectives

- Build a reproducible development environment using GitHub Codespaces.
- Organize the project using a structured machine learning repository layout.
- Apply GitHub Flow for feature development and experimentation.
- Prepare the project foundation for future hotspot forecasting and MLOps workflows.
